OVERVIEW
--------
This is a React e-commerce frontend educational course project.
The code emphasizes a clean, beginner-friendly, direct React coding style without 
over-engineering, unnecessary abstractions, or external backend dependencies.

COMPLETED WORK:
- Phase 1: Clean project foundation, routing, layouts, and initial structure.
- Phase 2: Complete Products Journey:
  1. Products Listing Page (/products):
     * Exactly 12 products per page.
     * Dynamic result counter: "Showing {start}-{end} of {total} results".
     * Category sidebar with 4 groups: Electronics, Fashion, Home & Living, Beauty.
     * Price range slider ($0 to $1,000+).
     * Rating filter (★★★★★ & Up with green stars).
     * Brand dropdown selector with real product brands.
     * Search bar in StoreNavbar with real-time filtering & auto page reset.
     * Sort dropdown (Newest Arrivals, Price Low-High, Price High-Low, Rating High-Low).
     * ProductsPagination (smart ellipsis, active purple page button).
     * ProductCard (discount badge, NEW badge, real image, links to /products/:id).
     * Enhanced No Results empty state with guidance and category pills matching Figma.
  2. Product Details Page (/products/:id):
     * Breadcrumb navigation (Home > Category > Brand > Title).
     * Two-column layout matching Figma reference.
     * Image Gallery with interactive vertical thumbnails strip.
     * Quantity selector bounded between 1 and product stock.
     * "Add to Cart" and "Buy Now" connected to global Cart state.
     * Specifications & Reviews tabs (with real customer reviews).
     * "Complete Your Setup" related products section.
- Phase 3: Cart, Checkout, and Order Confirmation:
  1. Global Cart State via Redux Toolkit:
     * Redux store configured in src/redux/store.js.
     * cartSlice providing: addToCart, increaseQuantity, decreaseQuantity, removeFromCart, clearCart.
     * Local Storage persistence under key `cartItems` (survives browser refresh).
     * Navbar cart badge displaying total units count across all items.
  2. Shopping Cart Page (/cart):
     * Interactive cart items list with image, title, variant, price, quantity controls, and remove action.
     * Order Summary calculating subtotal, FREE shipping, 8% tax, and total.
     * Express delivery estimate card.
     * "Proceed to Checkout →" navigating to /checkout.
     * Empty Cart state ("Your cart is feeling light") with 3D illustration and "Start Shopping" button.
  3. Checkout Page (/checkout):
     * Redirects to /cart when visited with an empty cart.
     * Visual progress steps: (1) Shipping ── (2) Payment ── (3) Review.
     * Controlled shipping form (First Name, Last Name, Address, City, Zip Code, Phone Number).
     * Frontend form validation with inline feedback.
     * Payment method selection (Credit/Debit Card with Card Number, Expiry, CVC vs PayPal).
     * Visual promo code input.
     * Order summary and security guarantee card.
     * Place order flow saving safe order data (excluding sensitive card info) to `lastOrder`.
  4. Order Confirmation Page (/order-confirmation):
     * Success checkmark with dynamic order number (#12345).
     * Estimated delivery date calculation (3-5 business days ahead).
     * Visual order progress tracker: Placed (✓) ── Processing (📦) ── Shipped (🚚).
     * Customer shipping address and shipping method details.
     * Order items summary breakdown.
     * "Continue Shopping" navigating to /products.
     * "Need help with your order?" 24/7 support banner.
     * Safe fallback if no recent order exists in storage.

TECH STACK
----------
- Vite (v8) + React (v19)
- Plain JavaScript + JSX (NO TypeScript)
- Redux Toolkit (@reduxjs/toolkit) + React Redux (react-redux)
- React Router DOM v7 (BrowserRouter, Routes, Route, NavLink, Link, Outlet, useParams, useSearchParams, useNavigate)
- React Bootstrap v2 + Bootstrap v5 CSS
- Axios v1 (used directly inside components)
- Custom Vanilla CSS (index.css, Products.css, ProductDetails.css, Cart.css, Checkout.css, OrderConfirmation.css)
- Linter: oxlint (0 warnings, 0 errors)
