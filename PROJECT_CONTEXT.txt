OVERVIEW
--------
This is a React e-commerce frontend educational course project.
The code emphasizes a clean, beginner-friendly, direct React coding style without 
over-engineering, unnecessary abstractions, or external state management libraries.

COMPLETED WORK:
- Phase 1: Clean project foundation, routing, layouts, and initial structure.
- Phase 2: Complete Products Journey:
  1. Products Listing Page (/products):
     * Exactly 12 products per page.
     * Real dynamic result counter: "Showing {start}-{end} of {total} results".
     * Category sidebar structured around 4 distinct category groups matching Figma:
       Electronics, Fashion, Home & Living, Beauty.
     * Price range slider ($0 to $1,000+).
     * Rating filter (★★★★★ & Up, etc. with emerald green stars).
     * Brand dropdown selector with real product brands.
     * Search bar in StoreNavbar with real-time filtering & auto page reset.
     * Sort dropdown (Newest Arrivals, Price Low-High, Price High-Low, Rating High-Low).
     * ProductsPagination (smart ellipsis, active purple page button).
     * ProductCard (discount badge, NEW badge, real image, links to /products/:id, UI-only Add button).
     * Explicit Loading (Spinner), Error with Retry, and Empty Results states.
  2. Product Details Page (/products/:id):
     * Breadcrumb navigation (Home > Category > Brand > Title).
     * Responsive two-column layout matching Figma reference.
     * Image Gallery with interactive vertical thumbnails strip.
     * Wishlist heart button (visual only).
     * Title, SKU, Rating, Reviews count, Price with discount calculation & shipping note.
     * Color selector (visual swatches).
     * Local quantity selector (1 to product stock limits).
     * "Add to Cart" (visual only) and "Buy Now" action buttons.
     * Guarantees grid (2-Year Warranty, 2-Day Delivery, 30-Day Returns, Lifetime Support).
     * 4-tab section: Specifications (with 3 spec cards), User Reviews (real reviews), Q & A, Downloads.
     * "Complete Your Setup" related products section (4 cards from same category).
     * Loading spinner, Error / 404 state with Retry button and link back to /products.

TECH STACK
----------
- Vite (v8) + React (v19)
- Plain JavaScript + JSX (NO TypeScript)
- React Router DOM v7 (BrowserRouter, Routes, Route, NavLink, Link, Outlet, useParams, useSearchParams)
- React Bootstrap v2 + Bootstrap v5 CSS
- Axios v1 (used directly inside components)
- Custom Vanilla CSS (index.css, Products.css, ProductDetails.css)
- Linter: oxlint (0 warnings, 0 errors)
- State Management: React useState / useEffect only (NO Redux, NO Context in this phase)
