KEY FILES CONTENT SUMMARY
--------------------------

main.jsx:
  - Imports React, ReactDOM, BrowserRouter from react-router-dom
  - Imports 'bootstrap/dist/css/bootstrap.min.css'
  - Imports App from './App.jsx'
  - Renders: <StrictMode><BrowserRouter><App /></BrowserRouter></StrictMode>

App.jsx (all routes are here):
  PUBLIC (no layout):
    /login        -> Login
    /register     -> Register

  STORE (wrapped in StoreLayout which renders Outlet):
    /             -> Home  (index route)
    /products     -> Products
    /products/:id -> ProductDetails
    /cart         -> Cart
    /profile      -> Profile

  DASHBOARD (wrapped in DashboardLayout which renders Outlet):
    /dashboard           -> Overview
    /dashboard/products  -> ProductsAdmin
    /dashboard/carts     -> CartsAdmin
    /dashboard/users     -> UsersAdmin

  FALLBACK:
    *             -> NotFound

vite.config.js:
  - Only has the React plugin
  - NO path alias (@ alias was removed in this cleanup session)

StoreLayout.jsx:
  - React Bootstrap Navbar (bg="dark" variant="dark")
  - Nav links using: <Nav.Link as={NavLink} to="...">
  - Links: Home, Products, Cart, Profile, Dashboard, Login, Register
  - Renders <Outlet /> below the Navbar
  - Comment at top: // Temporary navigation for testing the routes

DashboardLayout.jsx:
  - React Bootstrap Nav (flex-column) acting as a sidebar (Col md=2)
  - Links: Overview, Products, Carts, Users, Store
  - Renders <Outlet /> in the main content area (Col md=10)
  - Comment at top: // Temporary dashboard navigation

CODING STYLE RULES THIS PROJECT FOLLOWS
-----------------------------------------
- Normal relative imports ONLY: ./pages/Home  or  ../components/Navbar
- NO @ alias
- NO separate routes file (everything in App.jsx)
- NO ProtectedRoute until real auth is implemented
- NO Axios instance or interceptors until a real API call is needed
- NO Context until Context is actually implemented
- NO Redux, NO custom hooks, NO utils layer, NO service layer
- API calls will be written DIRECTLY inside components using axios when needed
- Style: beginner-friendly, direct, easy to read and trace for a React student
- Functional components only, no class components
